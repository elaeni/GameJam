# Team1

### CSPE Game Jam 2021

## JUMPONAUT

Help the lonely astronaut to survive in space
by moving platforms to jump on.
the platform controls are explained before a level starts.
- Move platforms so that the astronaut can jump on.
- The platform controls are explained before a level starts.
- If the astronaut gets stuck, you can restart the level in exchange for one of the lifes.
